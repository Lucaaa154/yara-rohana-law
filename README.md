# Yara Rohana Law Office

Official website for Adv. Yara Rohana Law Office, specializing in criminal law in Haifa, Israel.

## Tech Stack
- HTML5 / CSS3 / Vanilla JavaScript
- Hosted on Netlify
- Domain: yara-rohana-law.co.il

## Features
- Fully responsive (mobile-first)
- Hebrew RTL support
- Accessibility widget (WCAG 2.0 AA)
- Netlify Forms for contact
- SEO optimized with Schema.org markup
